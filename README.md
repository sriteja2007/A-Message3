# Will You Be Mine? ♥ — Moonlit Bloom

An interactive, cinematic romantic love letter web experience built with modern HTML5, CSS3, GSAP, Canvas, and Web Audio API. Inspired by the creative coding project shown on Instagram ([@saklin_01](https://www.instagram.com/reel/Db286ZXTfcJ/)).

![Preview](https://raw.githubusercontent.com/sriteja2007/A-Message3/main/preview.png)

## ✨ Experience Journey

1. **The Invitation (Hero Screen)**
   - Atmospheric midnight gradient with ambient floating motes and glowing stars.
   - Elegant header: *"for the one my heart beats for"*.
   - A pulsing, 3D radial-gradient SVG heart with heartbeat motion.
   - Interactive call-to-action: *"TOUCH THE HEART"*.
2. **Cupid's Arrow & Kinetic Typography**
   - Touching the heart triggers romantic background music and an animated Cupid's arrow streak.
   - 3D tilted kinetic typography reveals:
     - *"of all the hearts in all the world..."*
     - **"Will You Be Mine?"**
     - An animated golden loop doodle hand-drawn underneath.
   - A bright portal flash transitions into the starry night sky.
3. **The Blossom Trees ("you & me, under the stars")**
   - Two blossom trees grow organically across the canvas from the corners towards each other.
   - Hundreds of iridescent pastel heart-shaped petals pop and bloom on the branches, forming two lush heart foliage canopies.
   - Floating heart petals gently drift across the screen.
   - Radiant spotlight sunburst rays shine with badges: **"you"** and **"me"**.
   - Poetic quotes: *"you & me, under the stars"* & *"here's to us, and a love that blooms"*.
   - In the center spotlight, a glowing heart appears, Cupid's arrow shoots through it, and **"I love you"** glows in neon calligraphy.
4. **Celestial Constellation ("two wings, one sky" — "fly with me")**
   - Stardust dots ignite a sparkling heart constellation in the night sky.
   - Center statement: *"✦ two wings, one sky ✦"* & *"fly with me"*.
   - Two luminous winged creatures (one glowing cyan/blue, one glowing rose/pink) with fluttering 3D wings orbit gracefully around the constellation perimeter with sparkling stardust trails.
   - An interactive **"↺ AGAIN"** button enables seamless replaying.

---

## 🛠️ Built With

- **HTML5 & Modern CSS3** — Fully responsive for mobile phones, tablets, and desktop displays.
- **GSAP (GreenSock Animation Platform)** — Ultra-smooth, timeline-based animation sequences.
- **HTML5 Canvas 2D** — Procedural tree branching, blooming heart petals, drifting petals, and particle effects.
- **Web Audio API & HTML5 Audio** — Romantic background music with procedural music-box synthesizer fallback.
- **GitHub Actions** — Continuous automated deployment to GitHub Pages on every push.

## 🚀 Live Deployment via GitHub Actions

This repository is configured with a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically deploys the website to **GitHub Pages**.

### Enable GitHub Pages in Repository Settings:
1. Go to your repository settings: **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Every time code is pushed to `main`, GitHub Actions will build and deploy the live site automatically!
